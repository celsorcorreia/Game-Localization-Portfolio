# Game Localization Portfolio

Professional portfolio focused on **game localization, terminology management, narrative consistency, and technical documentation** for English and Brazilian Portuguese.

## Portfolio areas

- **Glossaries** — terminology resources organised by language.
- **Localization Samples** — translation, adaptation, editing, and localization rationale.
- **Iconia** — localization and documentation for an accessible fantasy card game.
- **Khaoz Age** — terminology, lore, and narrative localization for a fantasy RPG setting.
- **Resume** — professional profile in English and Brazilian Portuguese.
- **Website** — static portfolio published with GitHub Pages.

## Repository structure

```text
Game-Localization-Portfolio/

├── resume/
└── website/
```

## Working principles

1. Preserve gameplay meaning and player intent.
2. Maintain terminology consistency across UI, rules, narrative, and marketing text.
3. Adapt tone and cultural references without erasing the identity of the source.
4. Document decisions so localization remains scalable and reviewable.
5. Treat accessibility, readability, and context as part of localization quality.

## Languages

- Brazilian Portuguese (`pt-BR`)
- English (`en`)

## GitHub Pages

The website source is stored in [`website/`](website/). The workflow in [`.github/workflows/pages.yml`](.github/workflows/pages.yml) publishes that folder whenever `main` is updated.

After the first push, open **Settings → Pages → Build and deployment → Source** and select **GitHub Actions**.

## Content status

This repository is a living portfolio. Samples and glossary entries should identify their status as **Draft**, **Reviewed**, or **Final**.
