# Fifth Edition TTRPG Rules Localization

Independent English-to-Brazilian Portuguese localization case study using terminology and mechanics from the System Reference Document 5.1.

## Published files

- [Full case study](ttrpg-rules-localization-case-study.md)
- [Bilingual terminology](terminology.md)

## Focus

- core rules terminology;
- character statistics;
- d20 resolution mechanics;
- combat and action economy;
- spellcasting;
- conditions;
- metric conversion;
- rules style;
- linguistic and mechanical QA.
