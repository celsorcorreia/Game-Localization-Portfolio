# Fifth Edition TTRPG Rules Terminology

**Language pair:** English → Brazilian Portuguese  
**Source framework:** SRD 5.1  
**Status:** Working glossary

## Core rules

| English | Approved PT-BR | Category | Notes |
|---|---|---|---|
| Game Master | Mestre de Jogo | Table role | Use “Mestre” where context is unambiguous. |
| Ability | Atributo | Character system | Avoid collision with learned abilities. |
| Ability Score | Valor de Atributo | Character statistic | Base numerical value. |
| Ability Modifier | Modificador de Atributo | Derived statistic | Applied to relevant rolls. |
| Ability Check | Teste de Atributo | Resolution mechanic | Keep distinct from Salvaguarda. |
| Skill | Perícia | Character system | Specific training associated with an Atributo. |
| Difficulty Class | Classe de Dificuldade | Resolution target | Abbreviation: CD. |
| Saving Throw | Salvaguarda | Defensive test | Avoid “Teste de Resistência” because Resistência is a damage term. |
| Attack Roll | Jogada de Ataque | Combat test | Determines whether an attack hits. |
| Proficiency | Proficiência | Character system | Approved established term. |
| Proficiency Bonus | Bônus de Proficiência | Derived statistic | Approved established term. |
| Advantage | Vantagem | Dice mechanic | Roll two d20 and use the higher result. |
| Disadvantage | Desvantagem | Dice mechanic | Roll two d20 and use the lower result. |

| Concentration | Concentração | Magic rule | Formal defined term. |

## Rejected variants

| Preferred | Avoid | Reason |
|---|---|---|
| Atributo | Habilidade | Can collide with learned or class abilities. |
| Salvaguarda | Teste de Resistência | Collides with damage Resistência. |
| Deslocamento | Velocidade | Describes playable movement distance more precisely. |
| Espaço de Magia | Carga de Magia | Slot-based resource is clearer and more familiar. |
| Círculo da Magia | Nível da Magia | Avoids confusion with character level. |
| Contido | Imobilizado | Restrained does not always mean completely unable to move. |
