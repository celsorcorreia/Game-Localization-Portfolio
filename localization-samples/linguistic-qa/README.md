## About this sample

This folder contains a complete Linguistic Quality Assurance sample created for professional portfolio evaluation.

*Emberwake* is a fictional game build created solely for this case study. All strings, screens, bugs, translations, and reports are original examples. No client-confidential or copyrighted production material is included.

## Files

- [`qa-report.md`](qa-report.md) — complete methodology, severity model, findings, selected reports, and QA outcome.
- [`issue-log.csv`](issue-log.csv) — structured issue database containing 20 bugs.
- Visual case study — published through GitHub Pages at `website/case-studies/linguistic-qa.html`.

## Scope

The review covers:

- Terminology
- Grammar
- Context
- UI overflow
- Variables
- Tags
- Capitalization
- Mechanics
- Punctuation
- Consistency
