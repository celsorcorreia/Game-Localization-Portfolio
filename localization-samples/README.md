# Localization Samples

This directory presents original or properly authorised samples. Client-confidential content must never be published.

## Recommended sample format

1. Project and content type
2. Audience and platform
3. Source text
4. Target text
5. Constraints
6. Localization decisions
7. Alternatives considered
8. QA notes
9. Status

## Planned samples

- UI and menu strings
- Tutorial text
- Character dialogue
- Card abilities and rules text
- Lore and codex entries
- Store descriptions and marketing copy
- Linguistic QA report
