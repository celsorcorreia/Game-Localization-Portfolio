# Localization Samples

This directory presents original, openly licensed, or properly authorised samples. Client-confidential and copyrighted private-study content must never be published.

## Published samples

### Fifth Edition TTRPG Rules Localization

An English-to-Brazilian Portuguese rules localization study based on the openly licensed SRD 5.1.

- [Open the sample folder](ttrpg-rules-localization/)
- [Read the complete case study](ttrpg-rules-localization/ttrpg-rules-localization-case-study.md)
- [Review the terminology](ttrpg-rules-localization/terminology.md)

## Recommended sample format

1. Project and content type
2. Audience and platform
3. Source text
4. Target text
5. Constraints
6. Localization decisions
7. Alternatives considered
8. QA notes
9. Status
10. Source and licence
