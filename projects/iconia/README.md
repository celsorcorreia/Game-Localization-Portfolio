# Iconia — Localization Case Study

**Iconia: Bichos e Feitiços** is an original fantasy card game developed with an emphasis on approachable rules, visual identity, accessibility, and child-friendly language.

## Localization focus

- title and brand adaptation;
- ability and keyword terminology;
- concise rules text;
- consistency between icons and language;
- child-friendly readability;
- accessibility for colour-blind players;
- elemental identity across Portuguese and English.
