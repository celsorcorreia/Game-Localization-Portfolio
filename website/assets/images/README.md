# Case Study Visual Evidence

All images in this directory are original neutral mock-ups created for Celso Ricardo Correia's game-localization portfolio.

They do not reproduce client-confidential material or official artwork from third-party games.

## Folders

- `iconia/` — keyword and icon-language mock-ups for the original Iconia project.
- `khaoz-age/` — narrative comparison and divine-taxonomy diagrams for the original Khaoz Age RPG project.
- `ttrpg-rules/` — neutral rules and character-reference layouts. No official D&D artwork, trade dress, logos, or character-sheet design is used.
- `linguistic-qa/` — fictional bug-report and QA-coverage visuals.
- `ui-tutorial/` — fictional UI, tutorial, placeholder, and character-limit mock-ups.

## Formats

Images are exported as WebP at 1600 × 900 pixels for fast web delivery.
