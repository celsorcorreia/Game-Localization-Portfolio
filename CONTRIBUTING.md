# Contributing

This repository is maintained as a professional portfolio.

## Content rules

- Use UTF-8.
- Use clear file names in `kebab-case`.
- Identify language with `en` or `pt-BR` when relevant.
- Record terminology decisions in the appropriate glossary.
- Mark samples as Draft, Reviewed, or Final.
- Do not publish confidential client material.
- Replace client-sensitive content with anonymised or original examples.

## Commit style

Use concise imperative messages, for example:

- `Add Iconia keyword sample`
- `Review PT-BR combat terminology`
- `Update portfolio homepage`
