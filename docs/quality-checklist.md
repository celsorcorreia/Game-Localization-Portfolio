# Localization Quality Checklist

## Meaning

- [ ] Gameplay function is preserved.
- [ ] Narrative intent and tone are preserved.
- [ ] Ambiguities were resolved or documented.

## Language

- [ ] Grammar and spelling are correct.
- [ ] The text sounds natural in the target language.
- [ ] Register and character voice are consistent.

## Terminology

- [ ] Approved terms are used.
- [ ] Names, abilities, items, and systems are consistent.
- [ ] New terms were added to the glossary.

## Technical

- [ ] Variables, tags, line breaks, and placeholders are intact.
- [ ] Character limits were respected.
- [ ] UI context and text expansion were checked.

## Final review

- [ ] The sample includes context and rationale.
- [ ] Confidential information has been removed.
- [ ] Status is marked Draft, Reviewed, or Final.
