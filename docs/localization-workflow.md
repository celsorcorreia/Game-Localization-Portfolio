# Localization Workflow

## 1. Context review

Identify text type, character voice, gameplay function, UI limits, audience, platform, and dependencies.

## 2. Terminology preparation

Check existing glossaries, define new terms, identify forbidden variants, and flag ambiguous source strings.

## 3. Translation and adaptation

Translate meaning and function rather than surface words. Preserve tone, gameplay clarity, hierarchy, and player expectation.

## 4. Linguistic review

Review grammar, consistency, naturalness, terminology, punctuation, variables, tags, and character limits.

## 5. In-context review

Validate the text in menus, cards, dialogue boxes, tutorials, subtitles, and gameplay whenever builds or screenshots are available.

## 6. Documentation

Record decisions, unresolved questions, approved terms, and rationale for future consistency.
