# Glossaries

Terminology resources for English and Brazilian Portuguese.

## Structure

- [`en/`](en/) — English definitions, usage notes, and naming conventions.
- [`pt-br/`](pt-br/) — Brazilian Portuguese equivalents, definitions, and usage notes.

Each entry should include:

- source term;
- approved target term;
- part of speech or content category;
- definition;
- context;
- forbidden or deprecated variants;
- project;
- status.
